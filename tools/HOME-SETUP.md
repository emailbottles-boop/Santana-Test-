# Setting up the home computer, in one command

Paste this into **Command Prompt** (cmd) on the caretaker's computer (the one with the
scheduled task and wrangler already signed in). It clones this repository,
then hands Claude Code a precise list of what to do: merge, deploy, trim the
bars off every photo, re-point the scheduled task, run it once, and check the
live site. Claude stops and says so
if any step fails.

```
(where claude >nul 2>&1 || npm install -g @anthropic-ai/claude-code) && cd %USERPROFILE% && (git clone https://github.com/emailbottles-boop/Santana-Test-.git santana-site || echo already cloned) && cd santana-site && git fetch origin claude/santana-site-domain-outage-4hpsib && claude "This folder is the memorial website for Santana Turner (mahoganyjr.com and santanaturner.com). This is a Windows computer; run the .sh scripts with Git Bash, for example: bash deploy.sh. Do these steps in order, stop and tell me if any step fails, and do not skip ahead. 1) Put the site onto main: run 'git checkout main', then 'git merge --ff-only origin/claude/santana-site-domain-outage-4hpsib', then 'git push origin main'. If the fast-forward is refused, stop and show me the error; do not force anything. 2) Read README.md, the section called 'This repository, and where it came from'. 3) From the api folder run 'npx wrangler whoami'; if it is not signed in, run 'npx wrangler login' and wait for me to finish in the browser. 4) From the api folder run 'bash deploy.sh'. If it fails only because the zone for santanaturner.com cannot be found, comment out the two santanaturner.com lines in api/wrangler.toml, run deploy.sh again, commit that change with the message 'santanaturner.com waits for its Cloudflare zone' and push it, and tell me santanaturner.com still needs adding to Cloudflare. Change nothing else in that file. 5) Ask me for the caretaker password (the one for mahoganyjr.com/admin). Save it as the only line of tools/.admin-password (that file is gitignored and stays on this computer). Then run 'cd tools && npm install && node trim-all.mjs --dry-run' with ADMIN_PASSWORD set to it, show me the list of photos it would trim, and if it looks sane run it again without --dry-run. Show me tools/trim-all.log. 6) Find the scheduled task on this computer that runs an autodeploy.sh from the old WizardShit clone (use: schtasks /query /v /fo LIST | findstr /i autodeploy) and change that task so it runs tools/autodeploy.sh from THIS folder on the main branch instead, keeping the same schedule and the same way of launching bash. When done, summarise exactly what changed and what, if anything, is still waiting on me."
```
